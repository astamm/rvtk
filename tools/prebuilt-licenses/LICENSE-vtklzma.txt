liblzma / XZ Utils (VTK bundled compression library) - 0BSD (public domain)
===========================================================================

liblzma is VTK's bundled XZ compression library (headers under
ThirdParty/lzma/vtklzma; built as libvtklzma). It is redistributed inside the
pre-built VTK libraries shipped by the rvtk project (extracted into
inst/prebuilt from the vtk-<version>-*.tar.gz/.zip release archives).

The license text below is reproduced verbatim from the `COPYING` file shipped
in VTK's ThirdParty/lzma/vtklzma source tree at the v9.7.2 tag (commit
0558d4d4e4bc86c4b4bf7af2f2488011a4de9e0f; source:
https://github.com/Kitware/VTK). Only the liblzma library portions (0BSD /
public domain) are compiled into the shipped vtk archive; the xz command-line
tools and their getopt_long helper are not shipped.
