utf8 (VTK bundled UTF-8 string library) - Boost Software License 1.0
====================================================================

utf8 is VTK's bundled header-only UTF-8 string handling library
(ThirdParty/utf8/vtkutf8, installed as vtkutf8/utf8.h and friends). It is
redistributed inside the pre-built VTK libraries shipped by the rvtk project
(extracted into inst/prebuilt from the vtk-<version>-*.tar.gz/.zip release
archives).

The license text below is reproduced verbatim from the `LICENSE` file shipped
in VTK's ThirdParty/utf8/vtkutf8 source tree at the v9.7.2 tag (commit
0558d4d4e4bc86c4b4bf7af2f2488011a4de9e0f; source:
https://github.com/Kitware/VTK).
