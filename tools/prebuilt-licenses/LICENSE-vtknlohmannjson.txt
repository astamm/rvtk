nlohmann/json (VTK bundled JSON library) - MIT License
=======================================================

nlohmann/json is VTK's bundled JSON for Modern C++ header-only library
(ThirdParty/nlohmannjson/vtknlohmannjson, installed as vtknlohmannjson/json.hpp
and friends). It is redistributed inside the pre-built VTK libraries shipped by
the rvtk project (extracted into inst/prebuilt from the
vtk-<version>-*.tar.gz/.zip release archives).

The license text below is reproduced verbatim from the `LICENSE.MIT` file
shipped in VTK's ThirdParty/nlohmannjson/vtknlohmannjson source tree at the
v9.7.2 tag (commit 0558d4d4e4bc86c4b4bf7af2f2488011a4de9e0f; source:
https://github.com/Kitware/VTK).
