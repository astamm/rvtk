Theora (VTK bundled video codec) - BSD 3-Clause (Xiph.org)
=========================================================

Theora is VTK's bundled Theora video codec (headers under
ThirdParty/theora/vtktheora; built as libvtktheora). It is redistributed
inside the pre-built VTK libraries shipped by the rvtk project (extracted into
inst/prebuilt from the vtk-<version>-*.tar.gz/.zip release archives).

The license texts below are reproduced verbatim from the `LICENSE` and
`COPYING` files shipped in VTK's ThirdParty/theora/vtktheora source tree at
the v9.7.2 tag (commit 0558d4d4e4bc86c4b4bf7af2f2488011a4de9e0f; source:
https://github.com/Kitware/VTK). The COPYING file contains the BSD license;
the LICENSE file adds a patent non-assertion statement from On2 Technologies
regarding the underlying VP3 codec.
