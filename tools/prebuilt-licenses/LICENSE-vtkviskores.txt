Viskores (VTK bundled acceleration library) - Viskores License Version 1.2
===========================================================================

Viskores (formerly VTK-m) is VTK's bundled data-parallel computing library for
scientific visualization. It is redistributed inside the pre-built VTK
libraries shipped by the rvtk project (extracted into inst/prebuilt from the
vtk-<version>-*.tar.gz/.zip release archives) as the 23 `libviskores*`
archives plus `libviskoresdiympi_nompi.a`.

The license text below is reproduced verbatim from the `LICENSE.txt` file
shipped in VTK's ThirdParty/viskores/vtkviskores/viskores source tree at the
v9.7.2 tag (commit 0558d4d4e4bc86c4b4bf7af2f2488011a4de9e0f; source:
https://github.com/Kitware/VTK).

Bundled sub-components compiled into the `libviskores*` archives are covered
as follows: the vendored diy copy (`viskores/thirdparty/diy/viskoresdiy`,
built into `libviskores_cont` and `libviskoresdiympi_nompi`) carries the same
BSD-3-Clause (LBNL) license as `LICENSE-vtkdiy2.txt`; the vendored LCL copy
(`viskores/thirdparty/lcl/viskoreslcl`, built into `libviskores_cont` and the
filter libraries) is BSD-3-Clause (Kitware/NTESS/UT-Battelle/LANL); the
vendored lodepng copy (`viskores/thirdparty/lodepng/viskoreslodepng`, built
into `libviskores_io`) is zlib-style (Lode Vandevenne); the vendored loguru
copy (`viskores/thirdparty/loguru/viskoresloguru`, built into
`libviskores_cont`) is public domain. The viskores ZFP worklets
(`viskores/filter/zfp/worklet/zfp`) are covered by the Viskores license
itself.
