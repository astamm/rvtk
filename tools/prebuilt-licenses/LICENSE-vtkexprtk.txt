ExprTk (VTK bundled math expression library) - MIT License
==========================================================

ExprTk is VTK's bundled C++ math expression template library (header under
ThirdParty/exprtk/vtkexprtk/include/exprtk.hpp, installed as
vtkexprtk/include/exprtk.hpp). It is redistributed inside the pre-built VTK
libraries shipped by the rvtk project (extracted into inst/prebuilt from the
vtk-<version>-*.tar.gz/.zip release archives).

The license text below is reproduced verbatim from the `license.txt` file
shipped in VTK's ThirdParty/exprtk/vtkexprtk source tree at the v9.7.2 tag
(commit 0558d4d4e4bc86c4b4bf7af2f2488011a4de9e0f; source:
https://github.com/Kitware/VTK).
