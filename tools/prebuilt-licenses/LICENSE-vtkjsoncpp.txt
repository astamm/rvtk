JsonCpp (VTK bundled JSON parser) - Public Domain / MIT dual
============================================================

JsonCpp is VTK's bundled JSON parsing library (headers under
ThirdParty/jsoncpp/vtkjsoncpp; built as libvtkjsoncpp). It is redistributed
inside the pre-built VTK libraries shipped by the rvtk project (extracted into
inst/prebuilt from the vtk-<version>-*.tar.gz/.zip release archives).

The license text below is reproduced verbatim from the `LICENSE` file shipped
in VTK's ThirdParty/jsoncpp/vtkjsoncpp source tree at the v9.7.2 tag (commit
0558d4d4e4bc86c4b4bf7af2f2488011a4de9e0f; source:
https://github.com/Kitware/VTK). JsonCpp is released into the public domain in
jurisdictions that recognize public-domain dedication, and under the MIT
License in jurisdictions that do not; the user may choose either terms.
