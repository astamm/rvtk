KissFFT (VTK bundled FFT library) - BSD 3-Clause
================================================

KissFFT is VTK's bundled Fast Fourier Transform library (headers under
ThirdParty/kissfft/vtkkissfft; built as libvtkkissfft). It is redistributed
inside the pre-built VTK libraries shipped by the rvtk project (extracted into
inst/prebuilt from the vtk-<version>-*.tar.gz/.zip release archives).

The license text below is reproduced from the `COPYING` file shipped in VTK's
ThirdParty/kissfft/vtkkissfft source tree at the v9.7.2 tag (commit
0558d4d4e4bc86c4b4bf7af2f2488011a4de9e0f; source:
https://github.com/Kitware/VTK). The COPYING file states the library is
provided under the BSD 3-clause "New" or "Revised" License with SPDX
identifier BSD-3-Clause; the full text of that license (which is the same text
as the BSD-3-Clause variant used throughout VTK) follows.
