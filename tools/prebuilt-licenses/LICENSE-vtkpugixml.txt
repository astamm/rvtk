pugixml (VTK bundled XML parser) - MIT License
==============================================

pugixml is VTK's bundled lightweight XML processing library (headers under
ThirdParty/pugixml/vtkpugixml; built as libvtkpugixml). It is redistributed
inside the pre-built VTK libraries shipped by the rvtk project (extracted into
inst/prebuilt from the vtk-<version>-*.tar.gz/.zip release archives).

The license text below is reproduced verbatim from the `LICENSE.md` file
shipped in VTK's ThirdParty/pugixml/vtkpugixml source tree at the v9.7.2 tag
(commit 0558d4d4e4bc86c4b4bf7af2f2488011a4de9e0f; source:
https://github.com/Kitware/VTK).
