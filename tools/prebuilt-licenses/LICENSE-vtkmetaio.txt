MetaIO (VTK bundled medical image I/O library) - BSD 3-Clause (Insight Software Consortium)
===========================================================================================

MetaIO is VTK's bundled medical image MetaImage format I/O library (sources
under Utilities/MetaIO/vtkmetaio; built as libvtkmetaio). It lives in VTK's
Utilities/ tree rather than ThirdParty/ because Kitware maintains it as part
of VTK's own support code. It is redistributed inside the pre-built VTK
libraries shipped by the rvtk project (extracted into inst/prebuilt from the
vtk-<version>-*.tar.gz/.zip release archives).

The license text below is reproduced verbatim from the `License.txt` file
shipped in VTK's Utilities/MetaIO/vtkmetaio source tree at the v9.7.2 tag
(commit 0558d4d4e4bc86c4b4bf7af2f2488011a4de9e0f; source:
https://github.com/Kitware/VTK).
