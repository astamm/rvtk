vtkToken (VTK bundled token library) - BSD 3-Clause (Kitware)
=============================================================

vtkToken is VTK's bundled token library for interned-string representation
(headers under ThirdParty/token/vtktoken, installed as token/Token.h and
friends; built as libvtktoken). It was originally developed by Kitware as a
separate project and is vendored into VTK. It is redistributed inside the
pre-built VTK libraries shipped by the rvtk project (extracted into
inst/prebuilt from the vtk-<version>-*.tar.gz/.zip release archives).

The license text below is reproduced verbatim from the `license.md` file
shipped in VTK's ThirdParty/token/vtktoken source tree at the v9.7.2 tag
(commit 0558d4d4e4bc86c4b4bf7af2f2488011a4de9e0f; source:
https://github.com/Kitware/VTK).
