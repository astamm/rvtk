LZ4 (VTK bundled compression library) - BSD 2-Clause
====================================================

LZ4 is VTK's bundled lossless compression library (headers under
ThirdParty/lz4/vtklz4; built as libvtklz4). It is redistributed inside the
pre-built VTK libraries shipped by the rvtk project (extracted into
inst/prebuilt from the vtk-<version>-*.tar.gz/.zip release archives).

The license text below is reproduced verbatim from the `lib/LICENSE` file
shipped in VTK's ThirdParty/lz4/vtklz4 source tree at the v9.7.2 tag (commit
0558d4d4e4bc86c4b4bf7af2f2488011a4de9e0f; source:
https://github.com/Kitware/VTK).
