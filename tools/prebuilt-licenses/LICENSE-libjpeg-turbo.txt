libjpeg-turbo (VTK bundled JPEG library) - IJG / Modified BSD / zlib
====================================================================

libjpeg-turbo is VTK's bundled JPEG codec (headers under
ThirdParty/jpeg/vtkjpeg; built as libvtkjpeg). It is redistributed inside the
pre-built VTK libraries shipped by the rvtk project (extracted into
inst/prebuilt from the vtk-<version>-*.tar.gz/.zip release archives).

The license text below is reproduced verbatim from the "Libjpeg-turbo
Licenses" section of the upstream libjpeg-turbo LICENSE.md
(source: https://github.com/libjpeg-turbo/libjpeg-turbo, BSD 3-clause +
zlib/IJG; rendered for binary redistribution as required by its IJG clause 2).

------------------------------------------------------------------------------

libjpeg-turbo is covered by three compatible BSD-style open source licenses:

- The IJG (Independent JPEG Group) License, which is listed in
  README.ijg

  This license applies to the libjpeg API library and associated programs
  (any code inherited from libjpeg, and any modifications to that code.)

- The Modified (3-clause) BSD License, which is listed below

  This license covers the TurboJPEG API library and associated programs, as
  well as the build system.

- The zlib License

  This license is a subset of the other two, and it covers the libjpeg-turbo
  SIMD extensions.
