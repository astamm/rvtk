# Linker flags for packages linking against VTK

Returns the linker flags (`-L` paths and `-l` library names) required to
link C++ code against VTK. Intended to be called from a downstream
package's `configure` or `configure.win` script:

## Usage

``` r
LdFlags(modules = NULL, check = TRUE)
```

## Arguments

- modules:

  A character vector of VTK module names to link against, e.g.
  `c("vtkIOLegacy", "vtkCommonCore")`. When `NULL` (the default) all
  available modules are included. When non-`NULL`, only the requested
  modules are linked, which reduces link time and produces a smaller
  downstream package when only part of VTK is used.

- check:

  Whether to verify that every requested module is available in the
  detected VTK installation (see
  [`available_modules()`](https://astamm.github.io/rvtk/reference/available_modules.md))
  and fail with an actionable error when one is missing. Default `TRUE`.

## Value

A single character string of linker flags, written to stdout (so that it
can be captured by shell command substitution in `configure`) and
returned invisibly.

## Details

    VTK_LIBS="$("${R_HOME}/bin/Rscript" --vanilla -e "rvtk::LdFlags()")"

On Windows the full set of VTK linker flags can exceed the 8
191-character command-line limit. Prefer
[`LdFlagsFile()`](https://astamm.github.io/rvtk/reference/LdFlagsFile.md)
on Windows to write the flags to a response file instead.

## See also

[`use_rvtk()`](https://astamm.github.io/rvtk/reference/use_rvtk.md)
